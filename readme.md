# Дистрибутив ChiNux для Linux
## Про дистрибутив
* Этот дистрибутив в разработке
* Этот дистрибутив наследуется от Ubuntu
* Этот дистрибутив имеет два режима: Для небольшого/личного хозяйства, Для большого/коммерческого производства
* Есть аккаунты Lomantek ID и подписки Lomantek Ultimate и Lomantek Pro 
## Интерфейс
* В дистрибутиве используется свой UI
* Вы можете узнать больше про этот UI в репозитории "Chicken-UI-For-Linux" профиля владельца этого репозитория
## Режим небольшого хозяйства
* Панель управления Chicken Control Center и вкладка "Main" в панели управления Super Control Center
* При входе в аккаунт с Lomantek Ultimate/Pro вкладки Macros/IoT в Super Control Center не будут открыты
## Режим большого производства
* Панели управления Chicken Control Center и Super Control Center 
* Обязательная привязка к компании
* Полный доступ к панели управления при входе в аккаунт с Lomantek Pro/Ultimate
## Lomantek ID, Компании и привязка Ultimate/Pro
* Lomantek ID можно создать на сайте lomantek.localto.net
* Подписки Lomantek Ultimate/Pro можно купить на том же сайте
* Компании тоже можно создавать на сайте
* Lomantek Pro/Ultimate можно привязать на последнем экране настройки больше настроек -> Сервисы и подписки Lomantek Ultimate/Lomantek Pro -> В поле ключ ввести мастер ключ лицензии с сайта
